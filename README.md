## 📌 About The Project

**Creative Digital** is a modern and professional digital agency website designed to showcase creative services, digital solutions, projects, pricing plans, workflow, client testimonials, and contact information.

The website focuses on a **clean visual design, modern typography, responsive layouts, creative UI components, and a user-friendly browsing experience**.

This project was created as part of my **Frontend Web Development learning journey** to practice building a complete real-world agency website.
